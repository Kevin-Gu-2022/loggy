# Software User Manual
This document provides a brief overview of the functionalities of the Loggy device and how to use them.

## Device Interface
The device interface displays the real-time sensor readings as well as the alarm configurations and other settings. From left to right, the columns are:

- Channel Number
- Sensor Reading 
- Input Range 
- Alarm Status 
- Alarm Mode
- Alarm Low Threshold 
- Alarm High Threshold 
- Recording Status

Using the joystick, the user can move to all the cells. Pressing down on any cell in the Input Range column will switch the input range of that channel. Similarly, latched alarms can be unlatched by navigating to the relevant  latched alarm and clicking down. Recording can be started and stopped by clicking on any of the cells in the last column (i.e. the recording column). All the 8 channels can be viewed by continuously navigating down to scroll.

On the top right, the status icons from left to right represent:
- Recording Status
- PC Software Connection Status
- Optical Link Status
- Whether any alarms are active
